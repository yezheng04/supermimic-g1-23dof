# 10万轮之后checkpoint与8万轮的固定评测对比

日期：2026-10-31。远端正式训练已因Critic非有限梯度停止，本次没有恢复或修改训练。

## 结论

- 本次主样本完整回报最高仍为80k（0.8688），7个抽取的100k之后checkpoint均未超过。后期最高为152k（0.8299），失败8/2000，也多于80k的4/2000。
- 104k在困难组的完成覆盖最好：失败106/462，相比80k的135/462减少29条；但困难组平均回报0.6161仍低于80k的0.6309，主样本回报也下降。
- 104k尺蠖失败从19/22降至2/22，躺卧/起身名称组从37/54降至28/54。所有本次检查点的flip仍54/54失败，side_roll仍21/21失败。
- 104k和120k主样本失败3条，与80k的4条差异很小；考虑已有重复性限制，不据此宣称整体显著改善。
- 整体呈现反复退化与恢复，112k、140k尤其差；最后保存的156k回报0.5630、失败9条，不能因为最新就选它部署或展示。
- 建议保留80k作为当前固定子集最高回报基线；104k用于进一步检查已改善的困难动作。这里没有完成全库评测或真实机器人验证。

## 协议

沿用此前冻结的2,455条动作、同一缓存和50Hz时间轴。2,000条等概率主样本用于整体比较，462条困难组并集单列，去重合计2,455条；包含镜像片段。这是训练集覆盖评测，不是未见动作泛化测试，也不代表全库129,477条的最终结果。

本机RTX5080、256环境、seed=0，关闭噪声和域随机化、摩擦1.0，从首帧执行到片段末尾或原始失败条件。归一化回报按完整参考时长计算，提前终止的剩余部分计零。每个模型源文件和策略副本都检查哈希、迭代号和有限值。

8万轮在本次重新评测。已知GPU物理存在逐片段重复差异，接近的结果不能只凭一次运行断言显著改善。
