# Demo 重录与页面设计（2026-11-01）

## 官方页面核查

核查 [SuperMimic](https://supermimic.github.io) 的公开 HTML、CSS、`assets/js/site.js` 和四段视频，逐帧查看视频内容。引用素材仅用于研究，未作为本站资源发布。

- 首页为纯白舞台上的动作剪辑，无烧录字幕；网页负责标题和播放按钮。
- 世界模型区实际播放 `wm_on.mp4`、`wm_off.mp4`、`wm_slip.mp4`，并非网页实时计算预测。另有独立的实时 Web demo，不能与预录区混为一谈。
- 公开 JS 的播放时基为 50fps，组合片段 12.92 秒。翻转占帧 0–297，随后是跑动制动。模式切换保留当前时间和播放状态，页面绘制进度、帧号和事件标记。
- 官方显示白/黑机器人和逐渐变淡的蓝色预测姿态，纯白背景与柔和地面阴影。手机采用单独的视频构图。
- JS 标记策略关闭事件为视频 3.16 / 8.76 秒，低摩擦事件 9.74 秒、摩擦 0.3；这些是官方视频时间，不能套到我们的动作上。
- 没有从这些公开网页文件取得离线录制脚本、精确预测跨度、镜头参数、渲染器或“关闭策略”的底层执行定义。不能仅凭视觉认定其生成参数。

## 设计计划与复核

颜色：舞台白 `#ffffff`，段落浅灰 `#f5f5f7`，正文黑 `#1d1d1f`，辅助灰 `#6e6e73`，交互蓝 `#0071e3`，预测蓝 `#269de8`。

字体：Inter Tight 用于拉近官方效果的简洁标题；Inter 与系统中文无衬线用于正文，数字采用等宽数字特性。克制使用颜色，不给标题单词单独上色。

布局：居中首屏让机器人先成为焦点；动作选择器与大幅舞台结合；世界模型区左侧模式说明、右侧视频，共用底部时间轴；评测仍保留真实的 8 个 checkpoint。

```text
          标题 / 一句说明 / 论文与源码
                无字动作剪辑
       动作选择         机器人完整片段
       模式说明         仿真 + 预测残影
                  同步时间轴
          两列参考/策略诊断 + 评测
```

复核：原版的绿色强调、章节编号、深色方法块和重复大标题更像通用作品集。删除这些元素，把视觉重点集中在机器人运动；失败说明留在对应片段和评测中。保留我们的机器人、模型和事实，不套用官方成绩。

## 本次录制协议

重新执行 80k checkpoint 的 MuJoCo Warp 策略，50Hz、无随机化/噪声。正常模式每帧从当前状态与历史重新展开 32 步，未来动作由策略在预测状态上计算；只显示 +0.16 / +0.32 / +0.48 / +0.64 秒四个预测姿态。

对慢跑与跳跃录制干预分支，事件时刻统一为各片段的 2.0 秒。三个模式共享前 100 步轨迹；干预时复制基线的 qpos/qvel、求解器 warmstart、观测和动作历史，再改变执行条件。发布前核对前缀状态和动作完全一致，避免独立仿真的数值漂移混入干预对比：

- 策略执行：一直计算策略动作。
- 保持动作：2.0 秒后保持最后一个策略动作，PD 仍工作；不称为电机断电，也不宣称与官方 Policy off 的底层实现相同。
- 低摩擦：2.0 秒后足部摩擦从 1.0 改为 0.3，世界模型上下文同步读取实际摩擦。

触发训练终止后记录终止前状态并冻结，网页明确标记。参考与执行使用相同相机，禁止逐帧轨迹重新对齐。视频不烧录标题、时间轴或指标，控件由网页绘制。选择若干动作的演示不能代替统计评测。


## 重建命令

```bash
python3 scripts/download_demo_assets.py --models
PYTHONPATH=src MUJOCO_GL=egl .venv/bin/python scripts/record_showcase.py \
  --checkpoint models/models_0080000.pt \
  --library data/training/bones_seed_v4_full_v1/library_native23_fp16.pt \
  --output reports/showcase_new
PYTHONPATH=src MUJOCO_GL=egl .venv/bin/python scripts/render_showcase.py \
  --recording reports/showcase_new --output reports/showcase_new/render
```

输出为1280×720、50fps。地面柔和接触阴影是程序生成的展示着色，不参与物理或接触判定。所有播放状态、事件、帧号与图例由网页绘制；视频自身没有字幕。录制参数与每段终止时刻保存在 `website/data/showcase.json`。
