# 张量、训练结构和奖励

依据：[SuperMimic论文](https://arxiv.org/pdf/2610.28480)的§3、附录A/C/D；工程基础为Kang/Cuboi的第三方复现。以下明确区分公开约束与实现选择。

## 数据契约

统一Z-up、米、弧度。参考NPZ保存24个非world身体的世界坐标位姿、世界坐标线速度和角速度，按名称选14个身体计算奖励。CSV四元数为xyzw；raw GMR NPZ显式记录顺序；参考NPZ和MuJoCo为wxyz。所有NPZ读取禁止pickle。

状态 `s=[p_root(3), Q_root(4), q(23), v_root_world(3), omega_root_body(3), qdot(23)]`，59维。根位置减去环境原点，保留动作本身的全局平移。MuJoCo自由关节qpos30、qvel29。

注意：压缩参考库也是59维，但其根角速度字段存的是**world**；送进MuJoCo/FK时转换到body。不能将压缩参考直接当作WM状态。

| 输入 | 组成 | 维度 |
| --- | --- | --- |
| 动力学特征 | 根高1、去heading旋转6D、heading系根线速度3、body系根角速度3、q23、qdot23 | 59 |
| 仿真上下文xi | 足摩擦1、编码器偏差23、躯干COM偏移3 | 27 |
| 单帧本体观测 | q-q0+encoder_bias、qdot、body角速度、重力方向、上一步干净动作 | 75 |
| 10帧观测历史 | 每个字段内按旧→新排列，再拼字段；term-major | 750 |
| 单帧目标 | q_ref-q0(23)、qdot_ref(23)、参考重力3、参考body角速度3、参考heading线速度3、参考根高1 | 56 |
| 目标窗口 | 下一帧起的10帧，片段末尾clamp；不跨片段 | 560 |
| Actor输出 | 23维归一化关节目标偏移 | 23 |

上述具体状态/目标排列是工程选择，并非论文给出的官方张量规格。当前目标包含参考自身heading系速度，不包含相对机器人根位置误差；Critic额外接受根位置/朝向误差4维，来自参考复现的设计。

## 网络与更新

- Dynamics：SiLU MLP(2048,2048,2048)，输入59+23+27，输出58。末层零初始化；预测速度增量和位置修正，零输出时按常速度积分。
- Motion encoder：MLP(2048,1024,512,256) → 32维tanh latent。
- Decoder：latent32 + 750维历史 → MLP(2048,1024,512,256) → 23动作。
- Critic：canonical state、goal、xi及根误差 → MLP(256,128) → 标量。
- 终止头：根高/重力方向误差与绝对值4维 → MLP(64,64) → logit。

论文明确了主网络宽度、latent32、tanh、k=8、H=32等；SiLU、终止头规模、状态积分/归一化和末层初始化采用复现工程方案，不宣称原作者完全相同。

WM从Replay抽连续8步，自回归预测；按位置/旋转/线速度/角速度/关节位置/关节速度的尺度(0.05,0.1,0.5,1,0.1,2)归一化误差，坐标平方和加终止BCE，BCE权重1，再平均batch与时间。analytic reward和observation无需独立拟合。训练使用实际执行的带噪动作；Actor历史和动作平滑惩罚使用干净动作。

Actor冻结WM/Critic参数，但保持它们对输入的梯度；H=32展开，经可微FK算奖励，以软生存概率加权并使用末端价值。目标 `-J/H`；更新后恢复参数训练。Critic拟合detach的GAE目标，γ=.99、λ=.95。片段末尾令继续概率为0，Critic不学习重复末帧后的虚假转换。

默认优化器/学习率、批量、裁剪和调度在配置dataclass中；`configs/paper.json`使用论文规模，`rtx5080.json`缩小采样批量和环境数，不改主网络与展开长度。三个配置默认关闭torch.compile以减少初次编译和版本差异；并非论文速度基准。

## 奖励

每项先乘权重，再乘控制周期0.02秒。误差指数项形式为 `exp(-squared_error / std²)`。

| 项目 | 权重 | std |
| --- | ---: | ---: |
| 身体位置 | 1.0 | 0.3m |
| 身体旋转 | 1.0 | 0.4rad |
| 身体线速度 | 1.0 | 1.0m/s |
| 身体角速度 | 1.0 | 3.14rad/s |
| 根位置 | 0.5 | 0.3m |
| 根旋转 | 0.5 | 0.4rad |
| 动作变化平方和 | -0.1 | — |
| 关节软限位超出量之和 | -2.0 | — |

正奖励上界每步0.1。身体位置/旋转参考按机器人根XY/yaw重新对齐；根误差仍比较全局轨迹，身体速度比较世界系。根默认pelvis。高度偏差>.25m或重力z方向偏差>.8终止；片段结束和episode时限作为timeout区分。

域随机化：足摩擦U[.3,1.2]、关节编码偏差U[-.01,.01]rad、躯干COM偏移x±.025、y/z±.05m，按回合重采样。动作噪声N(0,.1²)，观测噪声沿用论文表A.1。无随机推力。Reset的姿态和速度扰动属于初始化扰动，区别于运行中推力。

## 时间和评测

控制50Hz，仿真200Hz，decimation4。环境推进目标之后再计算执行后奖励；奖励前调用forward解决mjlab1.2衍生身体状态滞后5ms的问题。相同规则用于终止头、WM窗口和imagination。

评测从每段第0帧开始，禁用观测/动作/重置噪声和随机化，摩擦固定1。N帧执行N-1步，分母为 `0.1*(N-1)`，提前失败后余下步按0奖励计算；同时输出实际执行步归一化值，避免把短暂不倒当成长轨迹成功。记录高度/倾斜失败原因。

这验证的是23自由度改型的复现。机器人自由度、数据重定向、数据划分和16GB批量均与论文实验存在差异，不能直接将单动作烟雾测试与论文大规模指标相比。
