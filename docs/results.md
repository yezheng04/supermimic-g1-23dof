# 固定动作集评测

2026-10-31 快照；2,000 条均匀主样本、462 条困难动作（重叠 7 条），合计 2,455 条不同动作。全部来自训练库，衡量覆盖程度，不是 holdout 泛化结果。所有 checkpoint 使用同一冻结清单、256 环境、首帧初始化、完整片段执行、关闭随机化与噪声、摩擦 1.0。

80k 在本次主样本平均回报最高，104k 困难动作失败最少。所有评测 checkpoint 均失败于全部 54 条翻转和 21 条侧滚。小幅失败数差异不意味着显著改善，仿真存在非确定性。

每条动作归一化回报为 `sum(rewards) / (0.1 * (reference_frames - 1))`，再对动作等权平均。提前终止时剩余回报为零，不缩短分母；回报不是成功率，也不保证非负。失败条件沿用训练：根高度误差超过 0.25m，或 pelvis 坐标下重力 z 分量之差绝对值超过 0.8；后者不是 0.8 弧度。

数据、来源 checkpoint 哈希、配置一致性与配对失败变化见 [`evidence/post100k/`](../evidence/post100k/)。完整原始轨迹/检查点在研究工作区，不随源码发布；表格可由该目录 `comparison.json` 重建。

本次长训练最后完成约 159,964 次迭代，因 Critic 非有限梯度停止，最新完整保存点为 156k。仓库整理没有重启该训练，也没有证明该问题已修复。
